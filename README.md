# 💥 SHAMSTECH JO — Solar Energy Web Platform

## 📌 Project Overview
**SHAMSTECH JO** is a clean, responsive web interface designed to simplify solar energy adoption for users in Jordan[cite: 2]. The platform acts as an interactive hub where clients can estimate their potential financial savings, explore solar system installation types, and request services easily[cite: 2].

---

## 💡 What the Project Does

### 1. Solar Savings & Financial Feasibility Calculator
Allows users to input their average monthly electricity bill (JOD) to instantly receive realistic financial projections, including[cite: 2]:
* **Recommended Solar System Capacity** (*kWp*)[cite: 2]
* **Expected Annual Monetary Savings**[cite: 2]
* **Payback Period / Return on Investment (ROI)** timeline in years[cite: 2]
* **Projected Net Savings** over a 25-year system lifespan[cite: 2]

### 2. Solar Installation & System Guide
Presents service offerings with clear explanations of different solar setups[cite: 2]:
* **On-Grid Systems:** Connected to the grid for bill reduction via net-metering[cite: 2].
* **Off-Grid Systems:** Battery-backed solutions for remote locations[cite: 2].
* **Hybrid Systems:** Grid connection combined with emergency battery backup[cite: 2].

### 3. Services & Support
Provides organized sections for booking maintenance, cleaning, dismantling, and equipment marketplace services[cite: 2].

## 🛠️ Tech Stack
This project was built cleanly using core web technologies[cite: 2]:
* **HTML5:** Semantic structure for a bilingual (Arabic/English) dark-mode UI[cite: 2].
* **CSS3:** Responsive styling, dark navy/gold visual theme, and custom UI components[cite: 2].
* **JavaScript (Vanilla ES6+):** Interactive logic for financial ROI calculations and DOM manipulation[cite: 2].
