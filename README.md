# Master-Piece-CSS
☀️ SHAMSTECH JO — Solar Energy Web Platform📌 Project OverviewSHAMSTECH JO is a clean, responsive web interface designed to simplify solar energy adoption for users in Jordan. The platform acts as an interactive hub where clients can estimate their potential financial savings, explore solar system installation types, and request services easily.💡 What the Project Does:Solar Savings & Financial Feasibility Calculator:
Allows users to input their average monthly electricity bill (JOD) to instantly receive realistic financial projections, including:Recommended solar system capacity ($kWp$).Expected annual monetary savings.Payback period / Return on Investment (ROI) timeline in years.Projected net savings over a 25-year system lifespan.Solar Installation & System Guide:
Presents service offerings with clear explanations of different solar setups:On-Grid Systems: Connected to the grid for bill reduction via net-metering.Off-Grid Systems: Battery-backed solutions for remote locations.Hybrid Systems: Grid connection combined with emergency battery backup.Services & Support:
Provides organized sections for booking maintenance, cleaning, dismantling, and equipment marketplace services.🛠️ Tech StackThis project was built cleanly using core web technologies:HTML5: Semantic structure for a bilingual (Arabic/English) dark-mode UI.CSS3 / Tailwind CSS: Responsive styling, dark navy/gold visual theme, and custom UI components.JavaScript (Vanilla ES6+): Interactive logic for financial ROI calculations and DOM manipulation.
